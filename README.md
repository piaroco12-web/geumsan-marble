# geumsan-marble
다 같이 돌자, 금산 한 바퀴 — 금산 체험 보드게임

「다 같이 돌자, 홍성 한 바퀴」(cne-localmarble)와 같은 방식으로 만드는 금산판입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 배포용 파일
```

Vercel에 올릴 때는 Framework를 Vite로 두면 됩니다.

## 폴더

| 위치 | 내용 |
|---|---|

| `ART_GUIDE.md` | 그림 규칙 요약, 사진 준비 안내 |

| `src/minigames.js` | 미니게임 3종 |
| `public/regions/geumsan/board.json` | 칸 위치(지도 1536×1024 기준), 장소, 말, 안내 캐릭터 |
| `public/regions/geumsan/questions.json` | 퀴즈 (`level`: low·high·both, `places`로 장소와 연결) |

## 규칙 (홍성판과 같음)

- 12턴, 하트 3개. 문제를 틀리거나 15초가 지나면 하트가 하나 줄어듭니다.
- 오늘의 도장 4곳(판마다 무작위)에서 문제를 맞혀 도장을 모으고 출발 칸으로 돌아오면 완주(+30점).
- 정답 +10점, 출발 칸을 지나면 +5점, 힌트 1번(틀린 보기 지우기), 금산 버스 3번(도장 장소로 바로 이동).
- 찬스 칸: 점수·버스표·하트·2칸 앞으로·깜짝 퀴즈·깜짝 미니게임 중 하나. 쉼터: 하트 1개 회복과 금산 이야기 카드.

## 미니게임

`board.json`에서 장소의 `mode`가 `quiz_or_minigame`이면 절반 확률로 미니게임이 나옵니다. 성공하면 +15점과 도장, 실패해도 하트는 줄지 않습니다. 첫 화면의 **🎮 미니게임만 해 보기**로 따로 연습할 수 있습니다.

| 미니게임 | 장소 | 방식 |
|---|---|---|
| 인삼 캐기 (`ginseng`) | 금산인삼관, 인삼약초시장 | 움직이는 바늘이 초록 칸에 올 때 당기기, 3번 성공 |
| 깻잎 짝 맞추기 (`memory`) | 추부 깻잎마을 | 카드 8장 짝 찾기 (쉬움 45초 · 보통 32초) |
| 위성 신호 맞추기 (`signal`) | 금산위성센터 | 화살표 명령을 순서대로 넣어 신호를 위성까지 보내기 (순차 명령, 기회 3번) |

## 선생님 설정 · 수업 시간 모드

첫 화면 왼쪽 아래 **⚙️ 선생님 설정**에서 바꿉니다. 설정은 그 기기 브라우저에만 저장됩니다.

| 항목 | 고를 수 있는 값 (기본값 굵게) |
|---|---|
| 턴 수 | 8 · **12** · 16 |
| 하트 | **3** · 5 |
| 문제 시간 | **15초** · 20초 · 30초 · 제한 없음 |
| 미니게임 | 끄기 · **보통**(절반) · 많이(80%) |
| 수업 시간 모드 | **끄기** · 15 · 20 · 30 · 40분. 시간이 지나면 진행 중인 턴이 끝날 때 결과 화면으로 넘어갑니다 |

## 오프라인 설치

배포된 주소를 한 번 열면 게임 파일과 `board.json`에 적힌 그림을 기기에 저장합니다(`public/sw.js`). 그 뒤에는 인터넷이 없어도 실행되고, 크롬·엣지에서 "앱 설치"로 바탕화면에 둘 수 있습니다. 개발 서버(`npm run dev`)에서는 꺼져 있습니다.

## 그림 용량

그림은 지금처럼 원본 PNG를 `public/regions/geumsan/art/`에 넣으면 됩니다. `npm run build`를 하면 배포용 `dist/`에만 화면 크기에 맞게 줄이고 압축한 그림이 들어갑니다(`scripts/optimize-art.js`, 원본은 그대로). 파일 이름과 형식이 같아서 `board.json`은 고치지 않아도 됩니다.

| 그림 | 최대 크기 |
|---|---|
| 지도 바탕, 첫 화면 배경, 인삼밭 배경 | 1600px |
| 카드 종이 무늬 | 768px |
| 캐릭터, 말, 화면(UI) 아이콘 | 384px |
| 건물, 미니게임 그림 | 512px |

2026-10-28 기준 그림 20장(아이콘 포함) 33.1MB → 2.5MB.
