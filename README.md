# geumsan-marble
다 같이 돌자, 금산 한 바퀴 — 금산 체험 보드게임

「다 같이 돌자, 홍성 한 바퀴」(cne-localmarble)와 같은 방식으로 만드는 금산판입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 배포용 파일
```

Vercel에 올릴 때는 Framework를 Vite로 두면 됩니다.

## 규칙 (홍성판과 같음)

- 12턴, 하트 3개. 문제를 틀리거나 15초가 지나면 하트가 하나 줄어듭니다.
- 오늘의 도장 4곳(판마다 무작위)에서 문제를 맞혀 도장을 모으고 출발 칸으로 돌아오면 완주(+30점).
- 정답 +10점, 출발 칸을 지나면 +5점, 힌트 1번(틀린 보기 지우기), 금산 버스 3번(도장 장소로 바로 이동).
- 찬스 칸: 점수·버스표·하트·2칸 앞으로·깜짝 퀴즈·깜짝 미니게임 중 하나. 쉼터: 하트 1개 회복과 금산 이야기 카드.

## 미니게임

`board.json`에서 장소의 `mode`가 `quiz_or_minigame`이면 절반 확률로 미니게임이 나옵니다. 성공하면 +15점과 도장, 실패해도 하트는 줄지 않습니다. 첫 화면의 **🎮 미니게임만 해 보기**로 따로 연습할 수 있습니다.

| 미니게임 | 장소 | 방식 |
|---|---|---|
| 인삼 캐기 (`ginseng`) | 금산인삼관, 인삼약초시장 | 움직이는 바늘이 초록 칸에 올 때 당기기, 3번 성공 |
| 깻잎 짝 맞추기 (`memory`) | 추부 깻잎마을 | 카드 8장 짝 찾기 (쉬움 45초 · 보통 32초) |
| 위성 신호 맞추기 (`signal`) | 금산위성센터 | 화살표 명령을 순서대로 넣어 신호를 위성까지 보내기 (순차 명령, 기회 3번) |
